A VLAN 
    - is a logical subnet or a logical network
    - it is a group of hosts with a common set of requirements attached to the same broadcast domain regardless of where they are physically located
    - it is a tool that we use to change the logical topology of a network without having to change the physical topology
    - 

The only way to traverse through VLAN devices are through the routers (level 3 devices)

Trunk Port is an interface will run a trunking protocol so that VLAN information can be transmitted from one switch to another. The industry standard is 802.IQ while ISL was previously used.

VTP (VLAN Trunking Protocol):
    - Layer 2 protocol
    - No connection with routers
    -  Three Modes
        - Server
        - Client
        - Transparent
    - VTP Domain:
        - Consists of one or more interconnected switches that share the same VTP domain name
        - Switches will only share VLAN information with other switches in the exact same information 
        - A switch can only belong to one VTP domain at a time
    - VTP Advertisements:
        - They are multicast frames over trunk line which switches use to share their VLAN database with their neighbor
    - Configuration Revision Number (CRN):
        - It is a 32 bit number that tracks the version of the VLAN database.
        - Everytime a change is made, the revision number increases by 1
    - Not recommended

Format of IPV6 address:
    - 128 bits in length in total
    - X:X:X:X:X:X:X:X
        - X is a 16 bit hexadecimal field
        - 2001:0000:130f:0000:0000:00d0:876a:123B 
    - Leading zeroes are optional
    - Successive fields of zeroes can be represented as ::
        - But only once per address
        - 2001:0000:130f:0000:0000:00d0:876a:123B  -> 2001:0:130f::0:00d0:876a:123B
        - 2001:0123:0000:0000:FFFF:0000:0000:0ABC  -> 2001:123::FFFF:0:0:ABC ->2001:123:0:0:FFFF::ABC
    - Loopback address is ::1

IPV6 Address Types:
    - Unicast:
        - Address for a single interface
        - Several types:
            - Global unicast address
            - Reserved unicast address
            - Link Local unicast address
            - Site Local unicast address (depracated)
        - Network Prefix (64 bits) containing Public Topology (First 48 bits) and SLA ID (next 16 bits), Interface Identifier (64 bits)
        - There is no subneting in IPV6 and is always 64 bits
        - There is no NAT like in IPV4
    - Multicast:
        - One to many
        - Enables more efficient use of the network
        - Uses a larger address range
        - Any address starting with FF02
        - There are no broadcasts
    - Anycast:
        - One to nearest (allocated from unicast address space)
        - Multiple devices share the same address
        - All anycast nodes should provide uniform service
        - Routers decide on closest devices to reach destination
        - Suitable for load balancing and content delivery services


IPV6 Aggregatable Global Unicast Address:
    - Internet Registry:
        - 2001::/16
    - ISP:
        2001:1234::/32
    - A particular organization (ex AWS)
        2001:1234:1::/64
    - A department of that particular organization 
        - 2001:1234:1:2::/64
        - 2001:1234:1:3::/64

IPV6 Routing Protocols: 
    - Static
    - PIPng (RFC 2080)
        - Distance Vector
        - Radius of 15 hops
        - Split horizon
        - Poison Reverse
        - Based on RIPv2
    - OSPFv3 (RFC 2740)
    - IS-IS for IPV6
    - MP-BGP4 (RFC 2545/2858)
    - EIGRP for IPv6

Open Shortest Path First (OSPF):
    - Resides at layer 3 directly on top of IP
    - Protocol ID is 89
    - It does not use RCP or UDP as a transport
    - It is a link state routing protocol wherein router exchange information of the
    state of links through state advertisements
    - It is an Interior Gateway protocol
Packet Types in OSPF:
    - Hello:
        - Dynamically discover neighbors
        - Form neighbor and maintain 
        - Default intervals
            - 10 seconds on broad segments (Ethernet)
            - 30 seconds on non-broadcast segments (Serial, NBMA)
        - Dead timer
            - 4 times hello interval by default
    - Database Description:
        - used to exchange brief versions of each LSA
    - Link State Request (LSR):
        - request for full LSA information
    - Link State Update
    - Link State Acknowledgement
